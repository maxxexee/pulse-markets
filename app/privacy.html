Privacy Policy

Last updated 17 November 2026

PULSE publishes a daily attention index. This page covers the landing site at /app/ and the pages beside it.

What this site stores

The page itself sets no cookies and runs no analytics or advertising scripts. It loads one local script (pulse-live.js) and one local set of images, and it fetches the published trends file from the same site.

The email field

The email field in the hero is a preview of the product's sign-up step. It is not connected to a mailing list: nothing is sent anywhere, and no address is saved. When a real sign-up exists, this page will name the processor before it accepts an address.

Hosting

The site is served by GitHub Pages. GitHub receives the usual request data for any site it hosts, including IP address, user agent and requested path, under GitHub's privacy statement.

Outbound links

Signal links open Wikipedia and Hacker News in a new tab. Once opened, those sites apply their own privacy policies.

Index data

The index is built from public aggregate counts (Wikipedia pageviews, Hacker News story counts) about public figures and topics. It does not profile individuals and holds no personal data about readers.

Contact

Questions or removal requests: open an issue at github.com/maxxexee/pulse-markets.
