How this demo is produced

The quote is a logistic function of the latest published index against this market's threshold: yes = 1 / (1 + exp(-(index - threshold) / scale)), clipped to 2 to 98 cents. scale is the standard deviation of day over day index changes inside this definition, clamped to 1 to 5.

Depth is a fixed ladder of one cent levels, eight a side, sized by a seeded generator so the same market and day always draw the same book. Seed: --.

The published evidence for this market's epoch: snapshot. The index chart reads api/index/history.
